# Packages

Nectar's core package, `@nectar-js/nectar`, handles commands, components, events, and the bot lifecycle. Start with [Installation](../getting-started/installation) to build a bot.

| Package | Use it to |
| --- | --- |
| [@nectar-js/create](./create) | Create a TypeScript or JavaScript project from the terminal. |
| [@nectar-js/i18n](./i18n/) | Translate replies, command names, and descriptions using JSON catalogs. |

Register i18n in the `plugins` array in `nectar.config.ts`. To write your own plugin, see the [Plugin API](../reference/plugins).
